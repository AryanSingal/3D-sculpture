# 3D Sculptures

A collection of interactive **3D sculptures and visual experiments** built with web technologies.

## ✨ Features

* Interactive 3D scenes
* Particle-based sculptures
* Glowing and cosmic effects
* Animations and visual effects
* Camera controls and interaction
* WebGL / Three.js experiments

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Three.js
* WebGL

## 📂 Project Structure

```text
sculptures/
├── sculpture-1/
├── sculpture-2/
├── sculpture-3/
└── ...
```

Each folder contains an individual sculpture or experiment.

## 🚀 Run

Open the HTML file in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🌌 Goal

Continuously explore and create new **3D sculptures, interactive experiences, and visual experiments** for the web.
